# Tricky Animals

**Prolog · graph search**  
**Course:** Utrecht University · Intelligent Systems

## Overview

A Prolog implementation of the Tricky Animals rearrangement puzzle, exploring valid moves and search.

## Project files

- `tricky.pl` — original Prolog source.

## Running the project

Open `tricky.pl` using a Prolog environment (for example SWI-Prolog); inspect the source for the original predicates and expected queries.

## Provenance

This repository preserves **original university coursework source files**. The interactive browser adaptations in the portfolio were built later and may use different implementations. No current build or hardware compatibility is guaranteed.
